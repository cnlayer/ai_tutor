## 1. 产品概述

### 1.1 背景与问题

家中有正在上小学和中学的孩子，日常功课辅导需求高频且分散：

- **答疑**：作业中遇到不会的题目，需要讲解思路；
- **解题**：数学、理化等题目需要分步求解与验证；
- **生词解释**：语文生字词、英语单词需要读音、释义、例句。

家长的痛点：**无法时刻陪在身边**。家长加班、外出或忙于家务时，孩子的问题得不到及时回应，只能：

- 空着不写、第二天问老师（问题积压）；
- 用手机自行搜索（内容不可控，容易直接抄答案，形成依赖）；
- 使用通用 AI 工具（不考虑年龄与年级，直接给答案，缺乏引导，且内容安全性无保障）。

### 1.2 产品定位

**一句话定位**：面向小学、中学孩子的家庭 AI 功课辅导助手——用语音、图片、文字自然提问，以启发引导的方式陪孩子想明白问题，背后可调度多种 AI 模型进行思考解析。

**产品原则**（所有需求取舍的依据）：

| 原则 | 含义 |
| --- | --- |
| 引导优先 | 默认不直接给答案，分步启发孩子思考，防止"抄答案依赖" |
| 年龄适配 | 语言难度、语气、示例、内容深度随孩子学段自动适配 |
| 多模态自然交互 | 会说就语音、会拍就拍照、会打字就打字，匹配不同年龄孩子的表达习惯 |
| 可靠可控 | 内容安全适龄、解答过程可靠、模型能力可由部署者配置管理 |

### 1.3 MVP 目标与验证问题

**MVP 目标**：在真实家庭场景中跑通最小辅导闭环——家长不在旁边时，孩子能**独立**完成"提问 → 获得引导 → 弄懂问题"。

**MVP 要验证的三个核心问题**：

1. **孩子愿不愿用、会不会用**：不同年龄段（尤其低龄）孩子能否独立完成提问与对话？
2. **引导式辅导是否有效**：孩子是被启发了，还是绕过引导直接要答案？
3. **多模型思考解析是否达标**：组合多个模型后的解答质量（准确性、讲解清晰度）能否满足功课辅导要求？

## 2. 目标用户与使用场景

### 2.1 用户画像

| 画像 | 描述 | 典型需求 | 交互偏好 |
| --- | --- | --- | --- |
| A：小学低年级（1–3 年级，6–9 岁） | 打字慢、识字量有限、表达口语化 | 生字词解释（含读音）、基础数学、看图提问 | 语音为主、拍照为辅；需要大按钮、少步骤、多鼓励 |
| B：小学高年级（4–6 年级，9–12 岁） | 有一定自主学习能力 | 应用题、语文阅读理解、英语入门、作文思路 | 拍照 + 文字混合 |
| C：中学生（12–15 岁） | 学业压力大，问题更深 | 数学、理化、英语语法与阅读、文科问答 | 文字 + 拍照；需要公式显示、深入讲解 |
| D：家长（部署者 / 决策者） | MVP 中不直接使用产品 | 首次配置（模型、孩子档案）、了解产品是否可靠 | 轻量配置入口；MVP 不做家长端功能 |

> 同一家庭中有多个不同学段的孩子，产品必须支持**多孩子档案**，并按档案适配辅导深度。

### 2.2 学科范围

- **核心学科（P0，必须达标）**：数学、语文（含生字词）、英语；
- **尽力支持（P1，能力范围内响应）**：科学、道德与法治、历史、地理、物理、化学、生物；
- **不在范围**：竞赛级专项培训、才艺类（音乐、美术等）辅导、体育。

### 2.3 典型使用场景

**场景 1｜晚间数学答疑（家长加班不在家）**
三年级的小明遇到一道不会的应用题，用平板打开网页，拍下了题目。AI 先复述题目确认理解无误，然后不直接给答案，而是反问："题目告诉了我们哪两个条件？"小明回答后，AI 肯定他想对的部分，再提示下一步。三轮对话后小明自己列出了算式，AI 播放语音表扬了他，并让他验算一遍。

**场景 2｜语文生词（低龄、语音优先）**
二年级的孩子读课外书遇到"璀璨"不认识，点击语音按钮问："璀璨是什么意思？"AI 先播放"璀璨"的标准读音，用孩子听得懂的话解释词义，给出一个贴近生活的例句，并配一张帮助理解的图片。

**场景 3｜中学几何（需要图示与完整解答）**
初二的小红做几何题卡住了，拍照提问。引导模式下 AI 给出辅助线思路并配示意图；小红尝试后仍未做出，主动切换到"完整讲解"模式，AI 给出完整解题步骤（公式正确显示），小红看完后追问其中一步的定理依据，AI 进一步解释。

**场景 4｜英语单词与阅读**
初一的孩子拍下一段英语课文，问其中一句的含义。AI 逐词朗读生词发音，解释句子结构和整句意思，并造一个新例句帮助孩子举一反三。

## 3. 核心用户旅程

```
打开网页
  → 选择 / 确认孩子档案
  → 首页提问（三选一：按住说话 ｜ 拍照/上传图片 ｜ 输入文字）
  → AI 理解问题（图片提问时展示提取的题目内容，可重新识别）
  → 引导式辅导对话循环：提示 → 孩子回应 → 反馈/深入
  → 孩子表示"懂了"（或切换"完整讲解"获得完整解答）
  → 会话自动保存，可在历史记录中回看
```

**旅程关键要求**：

- 从打开页面到发起第一次提问 **不超过 3 步**；
- 低龄孩子全程可只用语音完成一次辅导；
- 孩子中途离开再回来，能找回刚才的会话。

## 4. 功能需求

优先级定义：**P0 = MVP 必须实现；P1 = MVP 尽量实现（资源允许）；P2 = 本期明确不做**。

### FR1 孩子档案与首页（P0）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR1-1 | 支持创建多个孩子档案（昵称、年级），可随时切换；档案信息仅用于适配辅导内容 | P0 |
| FR1-2 | 首页常驻三个提问入口：语音按钮、拍照/上传图片按钮、文字输入框；界面对低龄儿童友好（大按钮、少文字、明确图标） | P0 |
| FR1-3 | 档案的学段自动影响 AI 的语言难度、语气与辅导深度（低年级短句口语多鼓励，中学严谨直接） | P0（基础适配）/ P1（精细化） |
| FR1-4 | 首次使用引导：授权麦克风/摄像头、创建档案、完成一次示例提问 | P1 |

**验收标准**：

- 可创建并切换至少 3 个孩子档案；
- 一年级孩子在不识读大量界面文字的情况下，能凭图标找到语音和拍照入口；
- 同一道数学题，在"三年级档案"和"初二档案"下得到的讲解深度有明显差异。

### FR2 文字输入与提问（P0）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR2-1 | 文字输入框支持中文、英文、数字与常用符号，回车发送 | P0 |
| FR2-2 | 支持在一次提问中组合多种输入：如图片 + 一句补充说明（文字或语音） | P0 |
| FR2-3 | 发送失败或网络异常时，输入内容不丢失，可重试 | P0 |

**验收标准**：中英文混合提问（如"explain 一下 'abandon' 怎么用"）能被正确理解并回答。

### FR3 语音输入（P0）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR3-1 | 点击/按住说话，语音实时转为文字显示，孩子确认后发送 | P0 |
| FR3-2 | 首次使用引导授予麦克风权限；权限缺失时给出明确的图文指引 | P0 |
| FR3-3 | 识别结果允许修改后再发送；识别失败或环境嘈杂时提示重试或改用文字 | P0 |
| FR3-4 | 针对儿童发音（吐字不清、语速不稳）优化识别可用性 | P1 |

**验收标准**：安静室内环境下，8 岁孩子用语音完整提出一个数学问题并得到正确响应的成功率 ≥ 80%（抽样测试）。

### FR4 图片输入（P0）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR4-1 | 支持两种方式：调用设备摄像头拍摄、从本地上传图片 | P0 |
| FR4-2 | 发送前可对图片进行简单的区域框选/裁剪，聚焦目标题目 | P0 |
| FR4-3 | AI 从图片中提取题目内容后，**展示给孩子确认**；提供"重新识别"入口 | P0 |
| FR4-4 | 识别结果支持逐字修正编辑（应对手写体、模糊图片的识别误差） | P1 |
| FR4-5 | 支持一次上传多张图片（跨页题目） | P1 |
| FR4-6 | 支持带几何图形、数学公式、表格的印刷体题目图片 | P0 |

**验收标准**：

- 拍摄一道印刷体初中数学题（含公式与图形），题目内容提取正确并进入辅导流程；
- 提取结果展示页上孩子可以一键"重新识别"或改用文字补充描述。

### FR5 引导式辅导对话（P0，产品核心）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR5-1 | **引导模式（默认）**：不直接给出最终答案；将问题拆解为小步骤，通过提示、反问、举例引导孩子自己得出答案；对孩子的每次回应给予肯定或纠正 | P0 |
| FR5-2 | **完整讲解模式**：给出完整解题步骤与原理说明；会话内可随时切换，**无需任何解锁**；切换选择被记住（下次默认沿用上次的模式）；每次切换行为记录在会话日志中，供家长后续查阅与产品观察分析 | P0 |
| FR5-3 | 孩子连续表示"不会 / 不懂"时，AI 自动降低难度、给出更明确的提示；连续 3 轮无进展时主动建议切换完整讲解 | P0 |
| FR5-4 | 孩子直接索要答案（"直接告诉我"）时，引导模式下 AI 温和坚持，先请孩子尝试一小步，而不是硬性拒绝造成挫败 | P0 |
| FR5-5 | 支持追问：孩子可对当前题目的任意步骤继续提问，AI 保持题目上下文 | P0 |
| FR5-6 | 每条 AI 回复旁提供"懂了 / 没懂"反馈按钮，反馈结果记录在会话中 | P0 |
| FR5-7 | 讲解完成后出一道同类小题让孩子验证是否真正掌握（孩子可跳过） | P1 |
| FR5-8 | 生词/生字类问题固定输出结构：读音（语音）→ 释义（适龄语言）→ 例句 → 配图（如适用） | P0 |

**验收标准**：

- 抽样 20 个引导模式会话，首轮回复直接包含最终答案的比例 ≤ 10%；
- 切换完整讲解后 5 秒内开始输出完整解答，且全程无需任何解锁步骤；
- 每次模式切换均可在会话记录中查到（时间、会话、孩子档案）；
- 生词提问按 FR5-8 固定结构输出。

**实现说明（v1.3 补充）**：FR5 的"引导模式默认"针对**作业与解题**类对话。实现里另有**直接讲解**回复模式，用于**知识性提问**（"黑洞是如何形成的""光合作用是什么"）——这类问题没有"孩子的解题思路"可引导，按年级水平直接给介绍更符合预期。用哪种模式由家长配置的**两份话题白名单**路由决定（见 [家长监护.md](./家长监护.md)）：作业类默认仍是引导模式，FR5-1 / FR5-4 的坚持策略与切换记录行为不变；家长可把 `directTopics` 置空回到全引导。

### FR6 多模态输出（P0 基线 + P1 增强）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR6-1 | **文字输出**：分步排版、重点突出；数学/物理公式正确渲染不乱码；代码或算式对齐清晰 | P0 |
| FR6-2 | **语音输出**：任意 AI 文字回复可一键朗读；生字、英语单词可单独播放标准读音；音色亲切、语速适合儿童 | P0 |
| FR6-3 | 朗读语速可调、可暂停/重播 | P1 |
| FR6-4 | **图像/图示输出**：在解释需要时输出辅助图片——词义插画、几何示意图（含辅助线）、函数图像、简单科学示意、汉字笔顺图等 | P0（基线：能配图）/ P1（增强：图示质量与分步呈现） |
| FR6-5 | 低年级孩子的汉字讲解可附拼音标注 | P1 |
| FR6-6 | 生成过程中的等待反馈（"正在思考"动效、进度提示），避免孩子以为卡死 | P0 |

**验收标准**：

- 英语单词提问可听到标准发音；
- 几何题讲解包含示意图；
- 含公式的数学解答在电脑和平板浏览器上显示正常；
- 任意 AI 回复可在 1 次点击内开始朗读。

### FR7 多模型思考解析（P0）

> 产品层面要求"可调用多种模型进行思考解析"；具体接入方式、路由实现属技术方案，另行文档化。

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR7-1 | 系统可接入**多个 AI 模型**作为思考解析引擎；模型来源支持**云端模型**与**本地模型**两类，可混合配置；新增/移除模型不需要改动孩子端界面 | P0 |
| FR7-2 | 面向部署者（家长）的**轻量配置入口**：管理可用模型清单（含云端/本地类型标识）、设置默认模型与调用策略；入口有简单访问保护（如口令），避免孩子误改 | P0 |
| FR7-3 | 模型调用对孩子**完全透明**：孩子无需感知、也看不到在用哪个模型 | P0 |
| FR7-4 | 主模型失败、超时或不可用时**自动切换**备用模型（云端模型与本地模型可互为备份），孩子端仅有正常的等待提示，不报错中断 | P0 |
| FR7-5 | 关键答案（如数学题最终结果）可用第二个模型**交叉核对**，不一致时重新解析或提示孩子"这道题建议再检查一遍" | P1 |
| FR7-6 | 可设置每日使用上限（次数/时长），达到上限时友好提示，防止过度使用与费用失控 | P1 |
| FR7-7 | 部署者可查看各模型的调用量与费用概况（简单统计即可，非家长端报告） | P1 |
| FR7-8 | 家庭外网不可用时，若已配置本地模型则自动改由本地模型应答，保障基本辅导能力（孩子端以温和方式提示当前为基础模式，不出现报错） | P1 |

**验收标准**：

- 模型清单中可同时配置云端模型与本地模型，两类模型均能正常应答；
- 在配置入口更改默认模型后，新会话由新模型应答；
- 人为使主模型不可用，孩子端提问仍能通过备用模型正常完成，无错误弹窗；
- 未通过口令无法进入配置入口。

### FR8 会话管理与历史记录（P0 基线）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR8-1 | 每次提问形成一个会话，完整保留文字、语音（转写文本）、图片、AI 回复及**辅导模式切换记录** | P0 |
| FR8-2 | 历史记录按孩子档案分组、按时间倒序展示，可打开回看完整对话（含朗读） | P0 |
| FR8-3 | 历史会话可**继续追问**（恢复上下文） | P1 |
| FR8-4 | 会话可按学科自动归类打标签，便于回看 | P2 |

**验收标准**：当天完成的辅导会话在历史记录中可见、可完整回放。

### FR9 内容安全与适龄性（P0）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR9-1 | 仅响应功课与学习相关话题；对无关或不当请求（暴力、成人内容、危险行为、诱导性话题等）**一律拒绝并温和引导回学习话题** | P0 |
| FR9-2 | 所有输出内容必须适合未成年人；即使孩子主动追问，也不提供不适宜内容 | P0 |
| FR9-3 | 对话中不主动索取孩子的个人敏感信息（学校全称、住址、联系方式等） | P0 |
| FR9-4 | 向使用者明示数据用途与去向：产品本地部署，照片、语音、对话数据默认保存在家庭本地设备，仅用于功课辅导；当问题交由云端模型解析时，提问相关内容会发送至对应模型服务商，声明页需明确告知（静态声明页 + 首次使用提示） | P0 |
| FR9-5 | 孩子或家长可对单条回复标记"这条不对 / 我不喜欢"，标记留存供家长抽查 | P1 |
| FR9-6 | 提供删除历史会话数据的能力 | P1 |

**验收标准**：

- 用 30 个典型不当话题样本测试，拒绝并引导的成功率 100%；
- 首次使用时可见数据用途说明。

## 5. 非功能需求（体验与质量层面）

| 类别 | 需求 |
| --- | --- |
| 响应速度 | 文字提问首个响应 ≤ 10 秒；图片提问（含内容提取）首个响应 ≤ 20 秒；超时须有明确进度反馈 |
| 语音质量 | 识别适配室内正常语速与儿童发音；朗读音色自然、无机械感 |
| 设备兼容 | Chrome / Edge（电脑）、iPad Safari、主流安卓平板浏览器；横竖屏均可用；手机浏览器尽力兼容 |
| 部署形态 | 产品本地部署于家庭设备（如家用电脑 / 小型服务器，需常开），孩子经家庭网络用浏览器访问；调用云端模型时需可访问互联网，调用本地模型时数据不出家庭网络 |
| 可用性 | 晚间作业高峰时段（18:00–21:30）稳定可用；单次故障不丢失孩子已提交的提问内容 |
| 易用性 | 低龄孩子在无成人帮助下可独立完成一次语音提问（作为验收测试项） |
| 界面语言 | 简体中文界面；英语学习内容支持英文原文展示 |

## 6. MVP 范围边界

### 6.1 范围内（本期交付）

多孩子档案 ｜ 文字/语音/图片输入 ｜ 文字/语音/图示输出 ｜ 引导式辅导（默认）+ 完整讲解（免解锁切换、后台记录）｜ 多模型接入（云端/本地混合配置）、部署者配置入口与自动切换 ｜ 会话历史（查看/回放）｜ 内容安全基线 ｜ 数据用途与去向声明 ｜ 本地部署形态。

## 7. 成功指标

**北极星指标**：每周每个孩子**独立完成**的引导辅导会话数（以孩子反馈"懂了"或完整看完讲解为完成标志）。

| 维度 | 指标 | MVP 目标 |
| --- | --- | --- |
| 可用性 | 新孩子首次使用时，独立完成第一次提问的比例 | ≥ 80% |
| 可用性 | 从打开页面到发起首次提问的操作步数 | ≤ 3 步 |
| 使用度 | 每孩子周均提问次数 | 持续增长（观察值，不设硬指标） |
| 使用度 | 低龄孩子（画像 A）提问中语音输入占比 | ≥ 40%（验证"语音优先"假设） |
| 辅导质量 | 孩子"懂了"正反馈率 | ≥ 70% |
| 辅导质量 | 数学题解答准确率（家长/人工抽样核查） | ≥ 90% |
| 教育理念 | 引导模式会话中，孩子平均表达自己思路的轮次 | ≥ 2 轮（验证孩子在思考而非索要答案） |
| 教育理念 | 完整讲解模式切换占比（来自后台记录） | 观察值，用于评估"免解锁"决策（Q2）是否需要调整 |
| 安全 | 不当内容输出事件数 | 0 |
| 满意度 | 家长定性访谈满意度（小样本家庭） | 正面为主 |

## 8. 风险与对策（产品层面）

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 模型给出错误答案，误导孩子 | 高 | 引导式过程降低对单次答案的依赖；交叉核对（FR7-5，P1）；"报个错"反馈入口（FR9-5）；家长通过历史记录抽查 |
| 孩子绕过引导直接要答案，产品沦为抄答案工具 | 高 | 引导模式为默认且策略坚持（FR5-4）；切换完整讲解免解锁但全程后台记录（Q2 决策），监控"孩子表达思路轮次"与"切换占比"指标并迭代话术；V1.1 家长端可查阅切换统计 |
| 儿童语音识别准确率低 | 中 | 识别结果先展示确认、可修改（FR3-1/3-3）；文字与拍照作为兜底通道 |
| 手写体/模糊图片题目提取错误 | 中 | 提取结果展示确认 + 重新识别（FR4-3）；逐字修正（FR4-4，P1）；提示重拍 |
| 多模型调用费用不可控 | 中 | 使用上限设置（FR7-6，P1）；部署者用量统计（FR7-7） |
| 未成年人数据隐私顾虑 | 高 | 产品本地部署，对话数据默认留存家庭本地（Q4 决策）；使用云端模型时透明告知数据去向（FR9-4）；数据最小化收集、可删除（FR9-6） |
| 浏览器权限（麦克风/摄像头）受阻导致无法使用 | 中 | 首次使用引导（FR1-4）；权限缺失时给出图文指引（FR3-2） |
| 家庭本地设备关机或服务未启动，孩子无法使用 | 中 | 部署选用常开设备；开机自启与异常自动恢复要求在技术方案中落实；家长可远程访问排查 |
| 本地模型能力有限，解析质量不及云端模型 | 中 | 部署者按学科/任务配置默认策略（FR7-2）；云端与本地互为备份（FR7-4/7-8）；解答准确率抽样核查覆盖本地模型 |
| 孩子对新工具三分钟热度 | 中 | 以成功指标持续观察；激励体系列入 V2 评估 |

## 11. 附录：术语表

| 术语 | 定义 |
| --- | --- |
| 引导模式 | 默认辅导方式：不直接给答案，通过分步提示、反问、举例引导孩子自己得出结论 |
| 完整讲解模式 | 给出完整解题步骤与原理说明的辅导方式，会话内可切换 |
| 思考解析引擎 | 产品中承担理解、推理、生成解答的 AI 模型能力的统称，可由多个模型提供 |
| 部署者 | 负责安装配置产品的家长（本家庭中即产品的发起使用者），拥有模型配置入口的访问口令 |
| 云端模型 | 通过互联网调用的第三方 AI 模型服务，能力强，但提问内容需发送至模型服务商 |
| 本地模型 | 运行在家庭本地设备上的 AI 模型，数据不出家庭网络，能力受家庭设备性能约束 |
| 孩子档案 | 代表一个孩子的轻量配置（昵称、年级），用于适配辅导内容与分组历史记录 |
| 会话 | 围绕一次提问展开的完整问答过程，含多轮对话与多模态内容 |
